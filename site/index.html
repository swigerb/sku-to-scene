    @foundry-router

    Model routing and cost guardrails

    Routing rules

    • Drafting / A-B testing → LTX-2.5 Fast or MiniMax H3 Max Turbo (Turbo for volume)
    • Approved hero image + native audio → Kling v3 Pro image-to-video
    • Strict multi-object layout → MiniMax H3 Max
    • Text brief + synchronized audio, final quality → LTX-2.5 Pro
    • Budget caps reserve the worst-case duration; unsupported settings are rejected or rerouted, never sent (LTX has no 1:1, so square PDP uses a documented crop policy).

    Per-clip estimate

    Preview list price × requested seconds. An estimate, not a bill. MiniMax output can run ~0.7 s longer than requested.
